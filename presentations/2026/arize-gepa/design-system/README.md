# Design system

This folder calibrates future Slidev slide/component generation.

Agents should inspect this folder before generating or changing visual design.

## Suggested files

- `tokens.css` — CSS custom properties and theme tokens.
- `colors.json` — named color palette.
- `typography.md` — font scale, weights, title/body conventions.
- `primitives.md` — shared classes such as panels, cards, badges, labels.
- `slide-patterns.md` — preferred slide compositions.
- `component-rules.md` — Vue component authoring rules.
- `samples/` — screenshots, images, or reference visuals.

Keep this folder small and opinionated. It is a contract, not a dumping ground.
